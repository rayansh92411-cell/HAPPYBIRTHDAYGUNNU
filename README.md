# Happy Birthday Gunnu ♥

GitHub Pages-ready customized birthday gift for Gunnu — 9 November.

## Important
This is a static version. GSAP is loaded from a CDN in `index.html`, so the Cupid arrow interaction works when hosted on GitHub Pages without running npm/Vite.

## GitHub Pages
Upload the contents of this folder to the repository root, with `index.html` at the root. Then enable Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
